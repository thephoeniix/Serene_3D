# Serene 3D

Herramientas web estáticas de Serene 3D. La página principal es `index.html` y enlaza las tres herramientas.

## Despliegue en Vercel

1. Importa el repositorio de GitHub en Vercel y selecciona la rama `main`.
2. Usa la raíz del repositorio como **Root Directory** y **Other** como framework.
3. Deja vacíos **Build Command** y **Output Directory**; no hace falta instalar dependencias.
4. Selecciona **Deploy**. Los siguientes cambios enviados a `main` generarán despliegues automáticamente.

El sitio es HTML estático: Vercel sirve `index.html` en la raíz y los enlaces a cada herramienta directamente.
